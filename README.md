# M.E. SIMULATOR
Senior Design Unity Project
Cleveland State University | May 2025

## Overview
This repository contains the code implemented for our Senior Design project, which creates simulated emergency response scenarios where the user will have the opportunity to learn how to respond to them and even save a person's life!

## Scenarios covered
1. Hypoglycemic Shock
2. Bullet Wound
3. Heart Attack
4. Basic Life Support (BLS)
